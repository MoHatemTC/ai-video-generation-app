# Prompts

Create AI prompt templates here.

Examples interns may create:

- `transcript.md` - generate a structured script from an instruction.
- `scene_planner.md` - break a script into scenes with visual cues.
- `visual_cue.md` - choose a visual type for a cue.

## Prompt Rules

- One prompt per file.
- Do not hard-code prompts inside Python files.
- Include the expected output format.
- Ask for JSON when the backend needs structured data.
- Tell the AI to stay factually accurate and not invent facts, definitions, sources, or data.
- Mention which service or pipeline stage uses the prompt.
